# Cat Adoption Website 🐱

以貓咪認養為主題所設計的前端網站，整合貓咪介紹、認養預約、會員介面、捐款與貓咪用品等功能頁面。

🔗 **Live Demo:**  
https://tienhsin-bob.github.io/cat-adoption-website/

## Project Overview

本專案為網頁程式設計課程的期末專題，主要透過 HTML、CSS、JavaScript、jQuery 與 Bootstrap 進行前端網站開發。

網站以「貓咪認養」為主題，設計完整的網站導覽與多個功能頁面，並練習響應式版面設計、網頁互動效果以及不同頁面間的整合。

## Features

- 貓咪認養資訊展示
- 認養預約介面
- Login / Sign Up 會員介面
- 捐款頁面
- 貓咪用品頁面
- 聯絡資訊與網站導覽
- 響應式網頁設計
- JavaScript / jQuery 網頁互動效果

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap

- GitHub Pages

## Notes

本專案主要著重於 Front-End 網頁設計與互動實作。

Login、Sign Up、預約及捐款等功能主要為前端介面展示，未串接正式的後端資料庫、會員驗證系統或金流系統。
